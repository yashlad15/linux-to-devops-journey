# Linux Basic Commands – Module 01

| Command | Purpose |
|---|---|
| whoami | Display current logged-in user |
| hostnamectl | Display hostname and OS information |
| pwd | Display current working directory |
| uname -r | Display Linux kernel version |
| cat /etc/redhat-release | Display RHEL version |
| lscpu | Display CPU information |
| free -h | Display RAM usage |
| lsblk | Display block devices and partitions |
| df -h | Display filesystem disk usage |
| uptime | Display system uptime |

## Practical Examples

### 1. Check Current User
```bash
whoami
```

### 2. Check Operating System
```bash
cat /etc/redhat-release
```

### 3. Check Memory
```bash
free -h
```

### 4. Check Disk Usage
```bash
df -h
```

### 5. Check CPU
```bash
lscpu
```

### 6. Check Kernel
```bash
uname -r
```

## Notes
Commands were practiced on Red Hat Enterprise Linux 9.6.
