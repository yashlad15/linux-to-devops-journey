# Module 01 – Linux Fundamentals

## Course Information
- Operating System: Red Hat Enterprise Linux (RHEL) 9.6
- Desktop Environment: GNOME
- Installation: Dual Boot
- Learning Level: Beginner
- Career Goal: DevOps Engineer

## 1. Introduction to Linux
Linux is an open-source operating system kernel. Linux-based distributions are widely used in servers, cloud computing, automation, and DevOps.

## 2. Linux Architecture

Main components:
1. Hardware – CPU, RAM, Storage.
2. Kernel – Manages hardware and system resources.
3. Shell – Provides an interface to interact with the operating system.
4. Applications – Software and services running on Linux.

## 3. Linux Distributions
- Red Hat Enterprise Linux (RHEL)
- Rocky Linux
- Ubuntu
- Debian

## 4. Practical Learning
Commands practiced:
- whoami
- hostnamectl
- pwd

- lscpu
- free -h
- lsblk
- df -h
- uptime

## 5. Learning Outcome
- Understand Linux fundamentals.
- Identify Linux distribution and kernel version.
- Check CPU, RAM and disk information.
- Navigate the Linux terminal.

## 6. Environment
